# 검은 달의 성채 — 궁수와 창병

Unity에서 `Assets/Scenes/SampleScene.unity`를 열고 Play를 누르세요.
Game 탭을 클릭하면 키보드로 조작할 수 있습니다. 오브젝트를 수동 연결할 필요는 없습니다.

## 캐릭터 선택

처음에는 캐릭터 선택창이 표시됩니다. 궁수 또는 창병을 선택하고 **전투 시작**을 누르세요.
`1` / `2` 또는 좌우 방향키로 선택하고 `Enter`로 시작할 수도 있습니다.
출전하는 플레이어는 항상 한 명이며 선택 중에는 전투가 진행되지 않습니다.

| 캐릭터 | 체력 | 직격 피해 | 공격 |
| --- | --- | --- | --- |
| 궁수 | 120 | 32 | 기존 활·화살, 범위 피해 반경 3.5m |
| 창병 | 140 | 40 | 긴 창 투척, 범위 피해 반경 1.5m |

두 캐릭터 모두 턴당 이동량은 10m입니다. 창병은 투구와 주황색 복장을 착용합니다.
전투 중 `Esc` 또는 **캐릭터 선택** 버튼으로 선택창에 돌아갈 수 있습니다.
캐릭터를 골라 전투를 시작하면 체력·적·턴·위치가 초기화됩니다.
`R`과 **다시 시작/다시 도전**은 현재 캐릭터로 재시작합니다.

## 구성

- 선택한 플레이어 1명, 적 4명(다리 파수꾼, 성채 대장, 절벽 사수, 하단 경비병)
- 왼쪽 절벽 → 중앙 다리와 낮은 발판 → 오른쪽 고지대·상하단 적진
- 도트 캐릭터, 픽셀 성채·달·폭포·횃불·깃발
- 왼쪽 플레이어 상태, 위쪽 턴 순서, 오른쪽 전장 정보, 아래쪽 조준·이동·발사 UI
- 카드, 재화, 장비, 바람, 거점 방어 등의 미구현 시스템은 표시하지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| A / D | 좌우 이동 및 바라보는 방향 변경 |
| W | 점프 |
| S | 얇은 다리나 발판에서 아래로 내려가기 |
| ↑ / ↓ | 각도 조절 (10~80도) |
| ← / → | 위력 조절 (10~38) |
| Space | 착지 상태에서 화살 발사 / 창 투척 |
| R | 다시 시작 |

화면 버튼으로 이동·점프·발사, 슬라이더로 조준할 수도 있습니다.
자기 턴마다 이동량 10m가 주어집니다. 점프는 1m를 소모합니다.
공중에서는 발사할 수 없고, 추락하면 체력 15를 잃고 마지막 발판으로 돌아옵니다.
다리 아래로 내려가 낮은 발판을 이용하거나, 다리 오른쪽 돌계단을 점프로 올라 고지대에 접근할 수 있습니다.

## 전투

플레이어는 턴당 한 번 공격할 수 있으며, 공격이 끝난 뒤에도 남은 이동량으로 이동·점프할 수 있습니다. 이동과 공격을 마친 뒤 화면 오른쪽 아래 **턴 넘기기** 버튼을 누르면 살아 있는 적들이 위쪽 순서대로 한 번씩 공격합니다.
그 뒤 플레이어 턴으로 돌아오며 이동량 10m와 공격 1회가 회복됩니다. 처치한 적은 순서에서 빠집니다. 공격 없이 턴을 넘길 수도 있습니다. 공격과 이동을 모두 소진해도 자동으로 턴이 종료되지는 않습니다. 비행·착탄 처리 중 또는 공중에서는 턴을 넘길 수 없으며, 전투 승패는 즉시 판정됩니다.
플레이어 체력은 궁수 120 / 창병 140, 일반 적은 40, 대장은 64입니다.
플레이어 직격 피해는 궁수 32 / 창병 40, 적 직격 피해는 10이며 근접 착탄도 작은 범위 피해를 줍니다.
화살과 창은 다리·절벽에 막히므로 높이와 거리를 고려해서 조준하세요.
모든 적을 처치하면 승리하며 플레이어 체력이 0이 되면 패배합니다.

## 코드

- `Assets/Fortress/FortressGame.cs`: 이동, 탄도, 충돌, 다수 적 턴, 승패
- `Assets/Fortress/FortressGame.Visuals.cs`: 도트 캐릭터와 지형 생성
- `Assets/Fortress/FortressGame.Hud.cs`: 한글 UI

외부 이미지 없이 생성하며 전장을 800×450 해상도로 렌더링하고 Point 필터로 확대합니다.
UI는 가독성을 위해 별도로 표시합니다. 화면 구성은 16:9 기준이며 다른 비율에서는 여백을 둡니다.
