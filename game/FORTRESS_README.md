# 검은 달의 성채 — 궁수와 창병

Unity에서 `Assets/Scenes/FortressBattle.unity`를 열고 Play를 누르세요.
Game 탭을 클릭하면 키보드로 조작할 수 있습니다. 기본 씬의 오브젝트 연결은 저장되어 있으며 Inspector에서 편집할 수 있습니다.

**지형·Prefab·능력치·UI 편집 방법은 [Unity 에디터 작업 안내](EDITOR_GUIDE.md)를 참고하세요.**

## 캐릭터 선택

처음에는 캐릭터 선택창이 표시됩니다. 궁수 또는 창병을 선택하고 **전투 시작**을 누르세요.
`1` / `2` 또는 좌우 방향키로 선택하고 `Enter`로 시작할 수도 있습니다.
출전하는 플레이어는 항상 한 명이며 선택 중에는 전투가 진행되지 않습니다.

| 캐릭터 | 체력 | 직격 피해 | 공격 |
| --- | --- | --- | --- |
| 궁수 | 120 | 32 | 기존 활·화살, 범위 피해 반경 3.5m |
| 창병 | 140 | 40 | 긴 창 투척, 범위 피해 반경 1.5m |

두 캐릭터 모두 턴당 이동량은 10m입니다. 창병은 투구와 주황색 복장을 착용합니다.
전투 중 `Esc` 또는 **캐릭터 선택** 버튼으로 선택창에 돌아갈 수 있습니다.
캐릭터를 골라 전투를 시작하면 체력·적·턴·위치가 초기화됩니다.
`R`과 **다시 시작/다시 도전**은 현재 캐릭터로 재시작합니다.

## 구성

- 선택한 플레이어 1명, 적 4명(다리 파수꾼, 성채 대장, 절벽 사수, 하단 경비병)
- 왼쪽 절벽 → 중앙 다리와 낮은 발판 → 오른쪽 고지대·상하단 적진
- 채색된 캐릭터 일러스트와 성채·달·폭포·횃불·깃발 배경
- 왼쪽 플레이어 상태, 위쪽 턴 순서, 오른쪽 전장 정보, 아래쪽 조준·이동·발사 UI
- 카드, 재화, 장비, 바람, 거점 방어 등의 미구현 시스템은 표시하지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| A / D | 좌우 이동 및 바라보는 방향 변경 |
| W | 점프 |
| S | 얇은 다리나 발판에서 아래로 내려가기 |
| ↑ / ↓ | 각도 조절 (10~80도) |
| ← / → | 위력 조절 (10~38) |
| Space | 착지 상태에서 화살 발사 / 창 투척 |
| R | 다시 시작 |
| Tab | 턴 넘기기 |

화면 버튼으로 이동·점프·발사, 슬라이더로 조준할 수도 있습니다.
자기 턴마다 이동량 10m가 주어집니다. 점프는 1m를 소모합니다.
공중에서는 발사할 수 없고, 추락하면 체력 15를 잃고 마지막 발판으로 돌아옵니다.
다리 아래로 내려가 낮은 발판을 이용하거나, 다리 오른쪽 돌계단을 점프로 올라 고지대에 접근할 수 있습니다.

## 전투

플레이어는 턴당 한 번 공격할 수 있으며, 공격이 끝난 뒤에도 남은 이동량으로 이동·점프할 수 있습니다. 이동과 공격을 마친 뒤 화면 오른쪽 아래 **턴 넘기기** 버튼을 누르면 살아 있는 적들이 위쪽 순서대로 행동합니다. 적마다 지형과 사격 가능성에 따라 제자리 공격, 이동 후 공격, 공격 후 이동을 선택합니다.
그 뒤 플레이어 턴으로 돌아오며 이동량 10m와 공격 1회가 회복됩니다. 처치한 적은 순서에서 빠집니다. 공격 없이 턴을 넘길 수도 있습니다. 공격과 이동을 모두 소진해도 자동으로 턴이 종료되지는 않습니다. 비행·착탄 처리 중 또는 공중에서는 턴을 넘길 수 없으며, 전투 승패는 즉시 판정됩니다.
플레이어 체력은 궁수 120 / 창병 140, 일반 적은 40, 대장은 64입니다.
플레이어 직격 피해는 궁수 32 / 창병 40, 적 직격 피해는 10이며 근접 착탄도 작은 범위 피해를 줍니다.
화살과 창은 다리·절벽에 막히므로 높이와 거리를 고려해서 조준하세요.
모든 적을 처치하면 승리하며 플레이어 체력이 0이 되면 패배합니다.

조준 중에는 **청록색에서 금색으로 이어지는 포물선 안내선**이 실제 탄도와 같은 계산으로 첫 충돌 지점까지 표시됩니다. 밝은 빛이 발사 방향으로 흐르고 예상 착탄 위치에는 맥동하는 금색 원이 나타납니다. 높은 각도에서는 안내선과 착탄 지점이 보이도록 카메라가 확대 범위를 조절하며, 화면에서 선의 굵기는 유지됩니다.

발사 후에는 궁수의 청록색, 창병의 금색, 적의 주황색 잔상이 탄환을 따라갑니다. 착탄 후 잔상은 짧게 사라지고 재시작·캐릭터 선택 시 초기화됩니다.

## 캐릭터 Animator

플레이어 두 직업과 모든 적에 Unity Animator를 연결했습니다. 기존 일러스트의 위치·회전·크기·색상을 애니메이션하는 방식이며, 대기는 호흡, 이동은 몸과 무기의 흔들림, 점프·낙하는 자세 변화로 표현합니다. 활은 당기기와 반동, 창은 뒤로 당긴 뒤 내미는 투척 동작을 사용합니다. 피해를 받으면 붉게 깜빡이며 흔들리고, 사망하면 쓰러진 뒤 사라집니다.

`Assets/Resources/FortressAnimation/Fighter.controller`를 더블클릭하면 Animator 창에서 상태와 전이를 볼 수 있습니다. 같은 폴더의 `.anim` 파일 9개는 Animation 창에서 수정할 수 있습니다.

| 파라미터 | 의미 |
| --- | --- |
| `Speed` | 실제 수평 이동 속도 |
| `Grounded` / `VerticalSpeed` | 착지 여부와 수직 속도 |
| `Aiming` | 해당 캐릭터의 조준 상태 |
| `BowAttack` / `SpearAttack` | 공격 모션 트리거 |
| `Hit` | 피격 모션 트리거 |
| `Dead` | 사망 상태 |

상태는 `Idle`, `Move`, `Jump`, `Fall`, `Aim`, `BowAttack`, `SpearAttack`, `Hit`, `Death`입니다. 공격 버튼을 누르면 준비 모션 후 활은 0.16초, 창은 0.22초에 발사됩니다. 준비 중에는 이동·추가 발사·턴 종료가 잠기며, 캐릭터 선택이나 재시작으로 취소할 수 있습니다. 사망한 캐릭터는 즉시 전투 판정에서 제외되고 0.9초 동안 사망 모션을 재생합니다.

런타임 계층은 캐릭터 루트 아래 `Motion`(Animator), 그 아래 `Body`와 `AimPivot/WeaponMotion`입니다. 애니메이션은 몸체와 무기 외형만 움직이며 이동 좌표, 충돌 범위, 탄도 계산은 기존 전투 코드가 담당합니다. 재시작과 직업 변경 시 모션·색상·투명도가 초기화됩니다.

에셋이 없으면 에디터에서 자동 생성합니다. **Mini Fortress → Rebuild Character Animations** 메뉴는 기본 컨트롤러와 클립을 다시 생성하므로 직접 편집한 애니메이션도 기본값으로 바뀝니다. 기본 공격 클립의 발사 키 시점을 수정할 때는 `Assets/FortressContent/Data`의 캐릭터 에셋에 있는 `Release Time`도 함께 맞추세요.

전장은 생성된 판타지 원화를 사용하며 1920×1080 해상도와 Bilinear 필터로 렌더링합니다. 캐릭터·무기는 원본 투명 PNG 아틀라스에서 미리 분리한 Sprite 에셋을 사용합니다. 발판 위치와 높이는 배경 원화의 지면에 맞춰 조정했습니다.
UI는 가독성을 위해 별도로 표시합니다. 화면 구성은 16:9 기준이며 다른 비율에서는 여백을 둡니다.

## 적의 전술 판단

적은 반드시 움직이지 않습니다. 현재 위치와 안전하게 이동할 수 있는 후보 위치에서 탄도를 계산합니다.
현재 자리에서 맞힐 수 있으면 먼저 공격하고, 이동이 사격 가능성을 충분히 개선할 때만 사격 전에 이동합니다.
공격 후에는 직전 플레이어 공격의 착탄 지점, 직선 사격을 가리는 지형, 다른 적과의 밀집도를 비교합니다.
더 안전한 후보가 있으면 남은 이동량으로 재배치하고, 이점이 없으면 그 자리에 머뭅니다.
공격 전후 이동을 합쳐 턴당 최대 4m이며 초당 3m 속도로 움직입니다.
현재 높이의 이어진 발판에서만 움직이고 절벽·단차·벽·살아 있는 다른 캐릭터를 통과하지 않습니다.
적의 점프와 발판 간 낙하는 포함하지 않습니다. 엄폐는 위험 점수에 반영되며 곡사 공격을 완전히 막는 것으로 간주하지 않습니다.
플레이어가 턴 넘기기를 누르기 전에는 적이 행동하지 않습니다.
