# 미니 포트리스

Unity에서 `Assets/Scenes/SampleScene.unity`를 열고 **Play**를 누르세요.
컴파일이 끝난 뒤 Game 탭을 클릭하면 키보드 조작이 가능합니다.
씬에 컴포넌트를 따로 연결할 필요 없이 실행 시 게임이 생성됩니다.

- 파란 탱크: 플레이어 / 빨간 탱크: AI
- 위·아래 방향키: 발사 각도 조절
- 왼쪽·오른쪽 방향키: 발사 세기 조절
- Space 또는 FIRE 버튼: 발사
- R 또는 RESTART 버튼: 처음부터 다시 시작
- 마우스로 각도·세기 슬라이더를 조작할 수도 있습니다.

중앙 장애물을 넘어 상대를 맞히세요. 양쪽 체력은 100이고 직격은 최대 40 피해입니다.
가까이 떨어진 포탄도 폭발 범위에 따라 피해를 줍니다. 한 발씩 번갈아 발사하며,
상대 체력을 먼저 0으로 만들면 승리합니다. 초기 각도 45도·세기 16으로 첫 발을 쏴보고 조절하세요.
점선은 발사 직후의 짧은 궤적만 보여줍니다.

기본 도형, 고정 지형, AI 한 대로 구성된 소형 프로토타입입니다.
이동, 지형 파괴, 바람, 멀티플레이는 포함하지 않습니다.
코드는 `Assets/Fortress/FortressGame.cs`에 있습니다. SampleScene에서만 자동 시작합니다.
